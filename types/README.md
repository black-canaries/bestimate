# Types

TypeScript type definitions shared across the app.

## Common Files

- `meal.ts` - Meal and food types
- `glucose.ts` - Glucose reading types
- `insulin.ts` - Insulin dose types
- `api.ts` - API response/request types

## Guidelines

- Use interfaces for object shapes
- Use type aliases for unions, intersections, etc.
- Export all types as named exports
- Keep types aligned with Convex schema
