# Constants

App-wide constants and configuration values.

## Common Files

- `glucose.ts` - Glucose range constants (normal: 70-180 mg/dL, etc.)
- `colors.ts` - Color constants (matching Tailwind theme)
- `app.ts` - General app configuration

## Guidelines

- Use UPPER_CASE for true constants
- Group related constants in the same file
- Export as named exports, not default
