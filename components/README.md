# Components

Reusable React Native components organized by feature.

## Structure

- `/meal` - Meal-related components (meal cards, meal forms, etc.)
- `/glucose` - Glucose-related components (glucose charts, reading displays, etc.)
- `/insulin` - Insulin-related components (dose forms, dose lists, etc.)
- `/ui` - Generic reusable UI components (buttons, inputs, cards, etc.)
- `/recommendations` - AI recommendation components

## Guidelines

- Keep components small and focused on a single purpose
- Use TypeScript for all components
- Use NativeWind (Tailwind) for styling
- Follow the component best practices in agent-os/standards/frontend/components.md
